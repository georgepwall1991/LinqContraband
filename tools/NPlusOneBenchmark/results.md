# N+1 benchmark results

Generated by `dotnet run --project tools/NPlusOneBenchmark/NPlusOneBenchmark.csproj -- --write`. Do not edit by hand; CI fails when this file is out of date.

Every case ran against SQLite with 3 and then 6 customers. A case is a proven N+1 when the larger database cost it more round trips, and proven safe when the count stayed the same. A round trip is one SQL command, or one `SaveChanges` call however many rows it writes. A case counts as reported when LC007, LC010, LC045 fires anywhere inside it with the package's default configuration.
